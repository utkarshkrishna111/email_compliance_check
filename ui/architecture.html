AI Agent Layer
🤖
AI Compliance Agent — LangChain + Azure OpenAI GPT-4o
Reads each email, detects sender intent, identifies non-compliant categories (market manipulation, bribery, secrecy, employee ethics, change in communication, complaints), extracts evidence lines, and produces a structured JSON finding with confidence score.
compliance_agent.py · LangChain · AzureChatOpenAI
Validation Layer
🛡️
Guardrails Validator
Validates AI output: checks required fields, confidence range, valid category IDs, evidence presence, reasoning length, and soft hallucination guard.
guardrails.py · GuardrailValidator
🔍
Verification Pass
Second LLM call challenges the initial finding, corrects categories / confidence if needed, and reduces hallucinations.
guardrails.py · ComplianceVerifier
Scoring & Output Layer
📊
Scoring Engine
Applies category base weights, multipliers (multi-category, high-confidence), normalises to 0–100 priority score and assigns band (CRITICAL / HIGH / MEDIUM / LOW).
scoring_engine.py · compliance_matrix.yaml
🗄️
Database / Storage
Scored findings persisted to JSON (output/compliance_results.json) for dashboard consumption and audit trail.
storage.py
🖥️
Dashboard
HTML dashboard (dashboard.html) uploads files, triggers analysis via REST API, and displays prioritised compliance findings with evidence and scores.
